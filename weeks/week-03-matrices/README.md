# Неделя 03. Матрицы как преобразования

> **Статус:** в разработке. Готового ноутбука пока нет.

**Вопрос недели:** как матрица действует на набор векторов?

**После работы студент сможет:** читать матрицу по её столбцам, вычислять образ вектора и связывать умножение матриц с композицией действий.

**Связь с программой:** раздел «Матричная алгебра», первая из трёх редакционных недель раздела.

**Возможная практика:** визуализировать образ координатной сетки при растяжении, сдвиге направления и их композиции; сравнить порядок преобразований.

См. [карту курса](../../docs/course-map.md) и [соглашения об обозначениях](../../docs/notation.md).
