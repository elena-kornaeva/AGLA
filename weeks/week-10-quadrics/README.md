# Неделя 10. Кривые и поверхности второго порядка

> **Статус:** оба ноутбука проверены локально в статическом режиме. Проверка в интерактивной среде Colab и публикация ещё предстоят.

**Вопрос недели:** как узнать кривую или поверхность по уравнению?

**После работы студент сможет:** выделять квадратичную и линейную части, узнавать основные типы коник и связывать уравнение поверхности с её сечениями.

**Связь с программой:** раздел «Кривые и поверхности второго порядка», первая из двух редакционных недель раздела.

**Практика:** «Кривое из прямого, свет из уравнений» — проектирование гиперболоидального каркаса и сравнение зеркал. Доступны черновики: [студенческий](notebooks/straight-structures-focused-light.ipynb) и [преподавательский](notebooks/straight-structures-focused-light-teacher.ipynb).

[Подробный план реализации (English)](tutorial-plan.md) содержит сценарий занятия, задания, формулы и проверки. Для просмотра черновика в Colab скачайте файл и выберите «Файл → Загрузить блокнот». Прямая ссылка появится после публикации и проверки.

**Локальная проверка.** Все кодовые ячейки выполнены по порядку в отдельных процессах Python 3.11.15 с NumPy 1.26.4 и Matplotlib 3.9.4. Проверены пустые и заполненные задания, крайние сечения каркаса, фокусировка параболоида, уточнение положения приёмника и сравнение апертур. Просмотрены десять статических рисунков.

См. [карту курса](../../docs/course-map.md) и [соглашения об обозначениях](../../docs/notation.md).
