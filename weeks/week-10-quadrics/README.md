# Неделя 10. Кривые и поверхности второго порядка

> **Статус:** оба ноутбука проверены локально в статическом режиме. Студенческий ноутбук версии 0.5.0 выполнен в Colab. Проверены ползунки каркаса и приёмника.

**Вопрос недели:** как узнать кривую или поверхность по уравнению?

**После работы студент сможет:** выделять квадратичную и линейную части, узнавать основные типы коник и связывать уравнение поверхности с её сечениями.

**Связь с программой:** раздел «Кривые и поверхности второго порядка», первая из двух редакционных недель раздела.

**Практика:** «Кривое из прямого, свет из уравнений» — проектирование гиперболоидального каркаса и сравнение зеркал. Доступны черновики: [студенческий](notebooks/straight-structures-focused-light.ipynb) и [преподавательский](notebooks/straight-structures-focused-light-teacher.ipynb).

- [Открыть студенческий ноутбук в Colab](https://colab.research.google.com/github/elena-kornaeva/AGLA/blob/main/weeks/week-10-quadrics/notebooks/straight-structures-focused-light.ipynb)
- [Открыть преподавательский ноутбук в Colab](https://colab.research.google.com/github/elena-kornaeva/AGLA/blob/main/weeks/week-10-quadrics/notebooks/straight-structures-focused-light-teacher.ipynb)

Для локальной копии выберите в Colab «Файл → Загрузить блокнот».

[Подробный план реализации (English)](tutorial-plan.md) содержит сценарий занятия, задания, формулы и проверки.

**Проверка в Colab.** Python 3.13.18, NumPy 2.4.6, Matplotlib 3.10.0, Plotly 5.24.1. При сдвиге до 180° каркас стал двойным конусом, а сечение талии стало точкой. При перемещении приёмника с 2,20 до 1,90 м синхронно изменились лучи, пятно и маркер на кривой RMS. После проверки в рабочей копии поправлены формат формул и размещение легенды каркаса.

**Локальная проверка.** Все кодовые ячейки выполнены по порядку в отдельных процессах Python 3.11.15 с NumPy 1.26.4 и Matplotlib 3.9.4. Проверены пустые и заполненные задания, крайние сечения каркаса, фокусировка параболоида, уточнение положения приёмника и сравнение апертур. Просмотрены десять статических рисунков.
