# Неделя 05. Системы линейных уравнений

> **Статус:** в разработке. Готового ноутбука пока нет.

**Вопрос недели:** как решить СЛАУ и проверить ответ?

**После работы студент сможет:** выполнять шаги метода Гаусса, различать единственное, бесконечное и отсутствующее решения и проверять найденный вектор подстановкой.

**Связь с программой:** раздел «Матричная алгебра», третья из трёх редакционных недель раздела.

**Возможная практика:** сопоставить ступенчатый вид с пересечением прямых или плоскостей и проверить невязку исходной, а не преобразованной системы.

См. [карту курса](../../docs/course-map.md) и [соглашения об обозначениях](../../docs/notation.md).
