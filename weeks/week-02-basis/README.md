# Неделя 02. Линейная зависимость и базис

> **Статус:** в разработке. Готового ноутбука пока нет.

**Вопрос недели:** когда описание избыточно и что значит базис?

**После работы студент сможет:** распознавать линейную зависимость, объяснять роль базиса и связывать число независимых направлений с рангом.

**Связь с программой:** раздел «Векторная алгебра», вторая из двух редакционных недель раздела.

**Возможная практика:** менять один вектор в наборе, наблюдать потерю независимости и проверять вывод решением небольшой линейной системы.

См. [карту курса](../../docs/course-map.md) и [соглашения об обозначениях](../../docs/notation.md).
