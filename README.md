# Аналитическая геометрия и линейная алгебра · МОИИ 2026

Учебный репозиторий для студентов первого курса направления 09.03.01 «Информатика и вычислительная техника», профиль «Математические основы искусственного интеллекта». Язык материалов — русский. Здесь темы курса превращаются в короткие воспроизводимые эксперименты: сначала геометрический вопрос, затем собственный расчёт, визуализация, проверка и связь с будущими задачами ИИ.

> **Статус:** готов первый практический ноутбук — [«Робот, камера и карта»](weeks/week-06-coordinate-systems/notebooks/robot-camera-map.ipynb), к лекции № 4 (редакционная неделя 06). Остальные материалы — редакционный план. Календарные недели ниже предложены для навигации по репозиторию; рабочая программа задаёт часы по восьми разделам, но не закрепляет эти разделы за конкретными неделями.

## Как устроен курс

Рабочая программа: 3 зачётные единицы, 108 академических часов, из них 60 лекционных, 30 практических, 9 самостоятельной работы и 9 часов контроля; итоговая форма — экзамен. Для репозитория 90 контактных часов распределены на **15 учебных недель по 4 часа лекций и 2 часа практики**. Самостоятельная работа следует распределению программы по разделам (1+1+1+1+1+1+1+2 = 9 часов), а 9 часов контроля учитываются отдельно. Это схема публикации материалов, а не утверждённое расписание.

## Формат каждой недели

1. **Входной вопрос** и то, что студент сможет объяснить после работы.
2. **Минимум теории** со ссылкой на лекцию и единым соглашением об обозначениях.
3. **Эксперимент** с изменяемыми параметрами, графиком и прогнозом до запуска кода.
4. **Практика**: одна задача с подсказками, одна проверка граничного случая и один вопрос «почему?».
5. **Мост к ИИ**: честная небольшая модель или игрушечные данные с явным указанием ограничений аналогии.
6. **Самопроверка**: численный инвариант, ожидаемый результат, вывод своими словами.

Для Colab предполагаются Python 3, NumPy и Matplotlib; интерактивные элементы через `ipywidgets` допустимы с обычным вариантом без виджетов. PyTorch добавлять только там, где он раскрывает тему тензоров, а не ради зависимости. GPU, внешние API и загрузка датасетов не нужны для основных заданий. Для запуска скачайте `.ipynb` со страницы недели и загрузите его в Colab через «Файл → Загрузить блокнот». Прямые Colab-ссылки появятся после публикации файлов.

## Лекция № 4: первая серия интерактивных историй

Три самостоятельных сценария в [docs/notebook-scenarios.md](docs/notebook-scenarios.md):

- **«Робот, камера и карта»** — переход между системами координат, перенос начала, пассивная смена описания и ошибка при косоугольном базисе.
- **«Поисковик без магии»** — проекции, косинусное сходство, влияние базиса и корректный скалярный продукт.
- **«Мастерская 3D-сцены»** — векторные нормали, ориентация граней, смешанное произведение и вырождение.

Это упражнения по математике на синтетических данных. Они показывают будущие применения в компьютерном зрении, поиске и 3D-обработке, но не требуют изученного курса машинного обучения.
