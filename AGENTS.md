## Математические соглашения

- Координаты векторов — столбцы. Если столбцы `P` — координаты нового базиса `G` в старом `E`, то `x_E = P y_G`, а новые координаты получают решением `P y_G = x_E`; для точки с новым началом `O'`, `x_E = a_E + P y_G`.
- В русской презентации `P` называется матрицей перехода «от E к G» по способу построения базиса. Во всех материалах поясняйте её фактическое действие на координаты `G → E`; не полагайтесь только на стрелку в названии.
- Различайте **пассивную** смену координат того же объекта и **активное** преобразование объекта при фиксированных осях. Для поворота новых осей на угол `φ` новые координаты исходного вектора равны `R(φ)^T x_E`.
- Формулы `a·b = a^T b` и обычная формула для векторного произведения по координатам требуют ортонормированного базиса; для косоугольного `G` используйте матрицу Грама `M = P^T P` и `a·b = y_a^T M y_b`. В 3D знак определителя координатной тройки зависит от ориентации базиса.
- Скалярное произведение возвращает число; векторное произведение в 3D — вектор; смешанное — ориентированный объём. В 2D `a_x b_y - a_y b_x` называйте ориентированной площадью/псевдоскаляром, а не обычным 2D-векторным произведением.
- Проверяйте область применимости: ненулевые нормы для косинуса и проекций, невырожденный базис для смены координат, неколлинеарные ребра для нормали. Отмечайте граничные случаи и численную погрешность.
- В исходной презентации встречаются неоднозначные или ошибочные записи формул. Перепроверяйте их выводом, геометрией и небольшим численным примером; сохраняйте согласованную математически корректную версию.

## Стандарт ноутбука

1. Заголовок, вопрос, предварительное предсказание и ожидаемые результаты.
2. Короткая «карточка инструментов» вместо пересказа лекции; ссылка на нужный раздел.
3. Одно визуальное наблюдение, затем незаполненный шаг студента, подсказка и явная самопроверка. Не показывайте готовый ответ до попытки, если это возможно.
4. Меняемый параметр с минимум двумя существенно разными режимами и подписанные оси/легенда. Для виджетов предусматривайте обычный запуск ячеек с заданными значениями.
5. Маленький мост к ИИ: какие величины соответствовали бы данным реальной задачи и почему синтетический пример не является обученной моделью.
6. Финальные вопросы на перенос знания, исследование вырожденного случая и один вывод словами студента.

Ноутбук должен выполняться в Colab сверху вниз с фиксированным генератором случайных чисел, если используется случайность. Основной путь: Python 3 + NumPy + Matplotlib, без GPU, сетевых запросов и секретов. Избегайте установки пакетов без необходимости. Не записывайте кодом правильные ответы в открытые ячейки упражнений; держите эталоны в отдельном блоке проверки или в материалах преподавателя.

## Проверка перед сдачей

- Выполнить все ячейки в чистой среде и сохранить ноутбук без громоздких выводов и персональных данных.
- Проверить численные инварианты на конкретных примерах: `P @ y == x`, `a + P @ y == x`, симметрию и положительную определённость матрицы Грама, ортогональность нормали рёбрам, изменение знака ориентированного объёма при перестановке вершин.
- Добавить осмысленные проверки там, где ошибка математически правдоподобна; не писать тесты, которые только повторяют ту же формулу.
- Проверить графики в светлой теме и доступные подписи; красный/зелёный цвет не должен быть единственным носителем смысла.
- Указать источник и лицензию для каждого внешнего изображения или набора данных. Для синтетических данных зафиксировать, что это учебная конструкция.
- Обновить `README.md` и недельную страницу при появлении реального ноутбука; не размещать нерабочие Colab-ссылки.
