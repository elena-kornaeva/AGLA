# Математические обозначения

Этот файл задаёт единые соглашения для лекционных заметок, задач и будущих ноутбуков.

## Векторы и координаты

- Координаты векторов записываются столбцами.
- `E = (e₁, …, eₙ)` — исходный базис, `G = (g₁, …, gₙ)` — новый базис.
- Столбец `j` матрицы `P` содержит координаты `gⱼ` в базисе `E`. Поэтому матрица `P` действует на координаты в направлении `G → E`:

  `x_E = P y_G`.

- Чтобы найти новые координаты того же вектора, решают систему `P y_G = x_E`. Запись `y_G = P⁻¹x_E` допустима только для невырожденной квадратной `P`; в вычислениях предпочтительнее решать систему, не формируя обратную матрицу явно.
- В русской презентации `P` может называться матрицей перехода «от `E` к `G`» по способу построения нового базиса. Рядом с таким названием всегда поясняется фактическое действие `G → E` на столбцы координат.

## Смена начала координат

Пусть начало новой системы имеет старые координаты `a_E`, а `y_G` — координаты точки относительно нового начала и нового базиса. Тогда

`x_E = a_E + P y_G`.

Обратный переход получают из системы `P y_G = x_E - a_E`. Для векторов свободный перенос начала не добавляется: он относится к координатам точек.

## Пассивное и активное преобразования

- **Пассивная смена координат:** геометрический объект тот же, меняется его описание. При повороте новых ортонормированных осей на угол `φ` координаты фиксированного вектора равны `R(φ)ᵀx_E`.
- **Активное преобразование:** оси фиксированы, а объект поворачивается. Его новые координаты равны `R(φ)x_E`.

Эти операции нельзя смешивать: при ортогональной матрице их формулы отличаются транспонированием, то есть знаком угла поворота.

## Скалярное произведение и матрица Грама

Формула `a · b = aᵀb` по координатам верна в ортонормированном базисе. Если столбцы `P` образуют косоугольный базис `G`, его матрица Грама

`M = PᵀP`,

а для координат `y_a` и `y_b` в этом базисе

`a · b = y_aᵀ M y_b`.

Матрица `M` симметрична. Для линейно независимых столбцов `P` она положительно определена. Косинус и ортогональная проекция требуют ненулевых норм.

## Ориентация и произведения

- Скалярное произведение возвращает число.
- Векторное произведение в трёхмерном ориентированном евклидовом пространстве возвращает вектор; стандартная координатная формула предполагает правый ортонормированный базис.
- Смешанное произведение задаёт ориентированный объём. Перестановка двух аргументов меняет его знак; нулевое значение соответствует вырожденной тройке.
- В двумерном случае `aₓbᵧ − aᵧbₓ` называется ориентированной площадью или псевдоскаляром, а не обычным 2D-векторным произведением.
- При смене ориентации базиса знак координатного определителя меняется. В косоугольном базисе нельзя без проверки переносить стандартные ортонормированные координатные формулы.

## Проверка формул

Каждую формулу следует проверять по трём линиям: вывод, геометрический смысл и небольшой численный пример. Обязательно отмечаются условия применимости: невырожденность базиса, ненулевые нормы, неколлинеарность рёбер для нормали и влияние вычислительной погрешности.
